Les Claude Skills sont des dossiers qui contiennent un fichier SKILL.md (nom, description, instructions) et parfois des références et des scripts. C'est quoi un skill Claude ?

Un skill (« compétence » dans l'interface française de Claude) est un dossier qui regroupe des instructions, des scripts et des ressources pour une tâche précise. Le centre d'aide d'Anthropic décrit ces dossiers comme des ressources « que Claude charge dynamiquement » : Claude repère les skills utiles à la demande en cours et ne lit que ce dont il a besoin.

Anthropic a lancé les skills le 16 octobre 2025, dans l'application Claude, dans Claude Code et dans l'API. Le 18 décembre 2025, l'éditeur a ajouté la gestion des skills à l'échelle d'une organisation, un répertoire de skills conçus par des partenaires, et a publié le format comme standard ouvert sous le nom Agent Skills, documenté sur agentskills.io. Vous croiserez donc les deux expressions : « Claude Skills » désigne la fonction dans les produits Claude, « Agent Skills » le format de fichier.

Concrètement, un skill transmet un savoir-faire : comment vous rédigez un compte rendu, comment vous auditez des balises, comment votre marque écrit un chiffre. Claude sait déjà rédiger, analyser et coder. Le skill lui apprend votre manière de le faire.

Comment Claude choisit et charge un skill

Le mécanisme s'appelle la divulgation progressive. Claude ne lit pas tous vos skills en entier à chaque message : il procède en trois niveaux, décrits dans la documentation d'Anthropic.

NiveauQuand Claude le litPoids dans le contexteContenu
1. MétadonnéesToujours, au démarrageEnviron 100 tokens par skillLe nom et la description
2. InstructionsQuand la demande correspond à la descriptionMoins de 5 000 tokens conseillésLe corps du fichier SKILL.md
3. RessourcesSeulement si les instructions y renvoientRien tant qu'elles ne sont pas luesFichiers de référence, modèles, scripts

Deux conséquences pratiques. Vous pouvez installer beaucoup de skills sans encombrer la conversation, puisque seule leur description reste chargée. Et tout se joue sur cette description : si elle ne dit pas clairement quand utiliser le skill, Claude ne l'ouvrira pas.

La structure d'un skill : SKILL.md, métadonnées et fichiers joints

Un skill est un dossier. Seul le fichier SKILL.md est obligatoire, le reste dépend de la tâche. La spécification Agent Skills recommande cette organisation :

controle-balises-seo/
├── SKILL.md       obligatoire : métadonnées et instructions
├── references/    facultatif : documentation à consulter
├── scripts/       facultatif : code à exécuter
└── assets/        facultatif : modèles, gabarits, données

Les métadonnées : name et description

Le fichier commence par un bloc YAML encadré par deux lignes de trois tirets. Deux champs sont obligatoires :

  • name : 64 caractères maximum, uniquement des minuscules, des chiffres et des traits d'union, sans trait d'union au début, à la fin ou en double. Il doit correspondre au nom du dossier. Les mots « claude » et « anthropic » sont réservés.
  • description : ce que fait le skill et quand l'utiliser, en 1 024 caractères au plus selon la spécification. Pour un import dans l'application Claude, le centre d'aide fixe la limite à 200 caractères : visez court.

Anthropic recommande d'écrire la description à la troisième personne (« Contrôle les balises… » plutôt que « Je peux contrôler… ») et d'y glisser les mots que vous employez dans vos demandes. Comparez :

  • Description faible : « Aide pour le SEO. »
  • Bonne description : « Contrôle les balises title et meta description d'un site et propose des corrections. À utiliser pour un audit de balises, de titles ou de meta descriptions. »

Les instructions en Markdown

Sous les métadonnées, vous écrivez librement en Markdown : les étapes, le format attendu, les règles, un exemple de bon résultat. Trois principes tirés des bonnes pratiques publiées par Anthropic :

  • N'expliquez pas ce que Claude sait déjà. Il connaît le SEO et le format CSV. Écrivez ce qui vous est propre : vos seuils, vos exceptions, votre format.
  • Restez sous 500 lignes. Au-delà, déplacez le détail dans des fichiers de référence.
  • Adaptez la liberté au risque. Une tâche fragile, comme un fichier de redirections, appelle des étapes exactes ; une tâche d'analyse supporte des consignes générales.

Les fichiers joints et les scripts

Les fichiers de référence se lisent à la demande : si la tâche n'en a pas besoin, ils ne coûtent rien. Les scripts s'exécutent sans être lus, et seul leur résultat entre dans la conversation, ce qui les rend plus fiables et plus économes qu'un code réécrit à chaque fois. Deux règles : renvoyez vers chaque fichier directement depuis SKILL.md, sans chaîne de renvois, et écrivez les chemins avec des barres obliques, comme references/seuils.md.

Les réglages propres à Claude Code

Claude Code accepte des champs supplémentaires dans les métadonnées. Les plus utiles :

  • disable-model-invocation: true : le skill ne se lance qu'à la main, avec /nom-du-skill. À réserver aux actions sensibles, comme un déploiement.
  • user-invocable: false : le skill disparaît du menu et reste une référence que Claude consulte seul.
  • allowed-tools : les outils que Claude peut utiliser sans demander d'autorisation pendant le tour où le skill est lancé.
  • context: fork : le skill s'exécute dans un sous-agent isolé, qui ne voit pas l'historique de la conversation.

Attention : pour un import dans l'application ou par l'API, seuls name, description, license, compatibility, metadata et allowed-tools sont acceptés. Un autre champ fait échouer l'import.

Où fonctionnent les Claude Skills : application, Claude Code et API

Le même format de dossier sert partout, mais chaque surface a ses règles.

Trois points à retenir. L'exécution de code doit être activée, sinon les skills ne fonctionnent pas. D'après le centre d'aide d'Anthropic, les skills fonctionnent sur toutes les formules, de la version gratuite à Enterprise. Et ils ne se synchronisent pas : un skill importé dans l'application n'existe ni dans l'API ni dans Claude Code, il faut l'installer sur chaque surface.

Les skills fonctionnent aussi dans Claude Cowork, le mode agent de Claude pour le travail de bureau, où ils arrivent souvent à l'intérieur de plugins, aux côtés de connecteurs et de sous-agents.

Comment installer un skill Claude

Dans l'application Claude

  1. Ouvrez Paramètres > Capacités et vérifiez que l'exécution de code et la création de fichiers est activée.
  2. Allez dans Personnaliser > Compétences.
  3. Cliquez sur +, puis Créer une compétence, puis Télécharger une compétence.
  4. Choisissez le fichier ZIP. Le dossier du skill doit se trouver à la racine du ZIP : mon-skill.zip contient mon-skill/SKILL.md, pas un fichier SKILL.md isolé.
  5. Activez le skill, puis testez-le dans une nouvelle conversation.

En formule Team ou Enterprise, l'administrateur doit d'abord autoriser l'exécution de code et les compétences dans Paramètres de l'organisation > Plugins et compétences. Dans Cowork, le répertoire de skills, ouvert depuis Personnaliser puis le bouton +, propose aussi des skills prêts à installer, dont ceux de partenaires comme Notion, Figma, Canva ou Atlassian.

Dans Claude Code

Claude Code lit les skills directement dans des dossiers, sans import. Si l'outil n'est pas encore sur votre machine, commencez par installer Claude Code.

  1. Copiez le dossier du skill dans ~/.claude/skills/ pour l'avoir dans tous vos projets, ou dans .claude/skills/ à la racine d'un projet pour le partager avec votre équipe via Git.
  2. Tapez /skills pour vérifier qu'il apparaît.
  3. Laissez Claude l'utiliser seul quand la demande correspond, ou lancez-le avec /nom-du-skill.

Pour installer les skills publiés par Anthropic, ajoutez leur dépôt comme place de marché de plugins, puis installez le lot qui vous intéresse :

/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills

Les anciennes commandes personnalisées, rangées dans .claude/commands/, continuent de fonctionner : Claude Code les traite désormais comme des skills.

Via l'API Claude

Côté développeurs, les skills passent par l'outil d'exécution de code. Vous déclarez le skill dans le paramètre container de la requête, avec son identifiant : pptx, xlsx, docx ou pdf pour ceux d'Anthropic, ou celui d'un skill que vous avez envoyé par les endpoints /v1/skills. Le skill tourne alors dans un conteneur sans accès à Internet, partagé avec tout l'espace de travail.

Où trouver des skills pour Claude

  • Le dépôt officiel anthropics/skills sur GitHub : skills de documents, de création, de développement et de communication. Anthropic précise qu'ils sont fournis à titre de démonstration et qu'il faut les tester avant de s'y fier.
  • Le répertoire intégré à Claude, avec les skills d'Anthropic et ceux de partenaires.
  • Les catalogues communautaires : il en existe plusieurs, qui recensent des milliers de skills de qualité très inégale. Lisez chaque fichier avant installation, la partie sécurité plus bas explique quoi vérifier.
  • Vos propres skills, souvent les plus utiles, parce qu'ils contiennent ce qu'aucun catalogue ne connaît : votre méthode.

Créer un skill Claude pas à pas

Un skill simple tient dans un fichier texte. La méthode qui suit vaut pour toutes les surfaces, seule la dernière étape change.

  1. Choisissez une tâche que vous expliquez souvent. Le bon candidat est la consigne que vous recopiez d'une conversation à l'autre : un format de rapport, une grille de contrôle, une charte.
  2. Faites la tâche une fois avec Claude, sans skill. Notez ce que vous devez préciser ou corriger : ce sont exactement les informations qui manquent à Claude, donc le contenu du skill.
  3. Créez le dossier et le fichier. Un dossier au nom du skill, en minuscules avec des tirets, et dedans un fichier SKILL.md.
  4. Écrivez les métadonnées. Le nom, puis une description qui dit ce que fait le skill et quand l'utiliser, avec les mots de vos demandes.
  5. Écrivez les instructions. Les étapes dans l'ordre, le format du résultat, les règles à respecter et, si possible, un exemple de résultat réussi.
  6. Ajoutez les fichiers utiles. Un barème dans references/, un modèle dans assets/, un script de vérification dans scripts/. Rien d'obligatoire.
  7. Testez sur trois vraies demandes. Dans une nouvelle conversation, formulez la demande comme d'habitude, sans citer le skill. Le raisonnement affiché de Claude doit indiquer qu'il lit le skill. S'il l'ignore, retravaillez la description.
  8. Installez-le selon la surface : ZIP dans l'application, dossier dans Claude Code, envoi par l'API.

Sans écrire une ligne : demander à Claude de créer le skill

Claude connaît le format. Après avoir fait une tâche avec lui, demandez-lui : « Crée un skill qui reprend la méthode que nous venons d'appliquer, avec les règles que je t'ai données. » Anthropic publie aussi un skill dédié, skill-creator, qui guide la création, la modification et le test d'un skill. Relisez toujours le résultat : un modèle a tendance à ajouter des explications inutiles, qu'il faut couper.

Dans Claude Cowork sur Mac, les formules Pro, Max et Team proposent aussi d'enregistrer un skill : vous réalisez la tâche à l'écran, pendant une dizaine de minutes au plus, et Claude propose un skill à partir de l'enregistrement. La fonction n'existe ni dans le chat, ni sous Windows, ni dans les formules gratuite et Enterprise.

Exemple complet de fichier SKILL.md

Voici un skill SEO complet, prêt à adapter. Il reprend la chaîne de contrôle des balises que je fais tourner sur mes missions avec Claude Code.

---
name: controle-balises-seo
description: "Contrôle les balises title et meta description d'un site et propose des corrections. À utiliser pour un audit de balises, de titles ou de meta descriptions."
---

# Contrôle des balises SEO

## Étapes
1. Lire l'export de crawl fourni (CSV) ou crawler les URL indiquées.
2. Repérer les titles absents, en double, de moins de 30 ou de plus de 60 caractères.
3. Faire de même pour les meta descriptions (absentes, en double, plus de 155 caractères).
4. Proposer une réécriture pour chaque page fautive, avec le nombre de caractères.
5. Ne modifier aucun fichier sans validation explicite.

## Format du résultat
Un tableau : URL, problème, balise actuelle, proposition, nombre de caractères.
Puis les cinq pages à traiter en premier, classées par trafic si l'export le contient.

## Règles
- Le title contient la requête visée par la page, au début si possible.
- Aucune promesse invérifiable (« le meilleur », « n° 1 »).
- Signaler les cas ambigus dans une liste à arbitrer au lieu de trancher.

## Référence
Seuils et exceptions propres au site : voir references/seuils.md

    Skills, projets, MCP, sous-agents : quelles différences ?

    Claude propose plusieurs façons de lui donner du contexte, et elles se confondent facilement. Anthropic résume la distinction ainsi : un projet dit à Claude ce qu'il doit savoir, un skill lui dit comment faire, et le MCP le relie à vos données.

    ÉlémentÀ quoi il sertQuand il agitExemple
    PromptUne demande ponctuelleLe temps d'une conversation« Résume ce compte rendu en cinq puces »
    Instructions personnalisées, CLAUDE.mdVos préférences généralesDans toutes les conversations, ou tout le projet de code« Réponds en français, sans emojis »
    ProjetUne base de connaissances sur un sujetDans les conversations du projetLes documents d'un client
    SkillUne méthode pour une tâche préciseSeulement quand la demande correspondVotre grille d'audit des balises
    MCP, connecteurL'accès à un outil ou à des donnéesQuand Claude appelle l'outilLa Search Console, un crawler, Notion
    Sous-agentUn assistant spécialisé, avec son propre contexteQuand une tâche lui est déléguéeUn relecteur de code dans Claude Code
    PluginUn paquet qui regroupe skills, connecteurs et sous-agentsUne fois installéUn lot marketing pour toute une équipe

    Skill ou projet. Un projet stocke de la matière (documents, consignes générales) disponible dans toutes ses conversations. Un skill stocke une procédure, chargée seulement quand elle sert, dans n'importe quelle conversation, quel que soit le projet.

    Skill ou MCP. Le MCP donne des outils à Claude : lire la Search Console, lancer un crawl. Le skill lui dit quoi en faire : quelles pages comparer, quels seuils appliquer, quel tableau rendre. Les deux se combinent, et c'est souvent la meilleure configuration. Je détaille le fonctionnement d'un serveur MCP dans un article dédié.

    Skill ou sous-agent. Un sous-agent est un assistant complet, avec son propre contexte, à qui l'agent principal délègue une partie du travail. Un skill est un savoir-faire que n'importe quelle instance de Claude peut charger. Dans Claude Code, les deux se rejoignent avec context: fork, qui fait tourner un skill dans un sous-agent. Pour la logique d'agent en général, voyez comment créer un agent IA.

    10 exemples de skills Claude, dont 6 pour le SEO

    Les quatre premiers sont fournis par Anthropic ou ses partenaires, ou s'écrivent en quelques lignes. Les six suivants reprennent les tâches SEO que j'automatise avec Claude Code en mission : chacune a une donnée d'entrée propre, une règle explicite et un résultat vérifiable, ce qui en fait de bons candidats.

    Les skills prêts à l'emploi et les skills métier

    1. Les skills de documents d'Anthropic

    Word, Excel, PowerPoint et PDF : Claude les utilise de lui-même quand vous demandez un document, dans l'application comme par l'API. Ce sont eux qui lui permettent de produire un tableur avec des formules ou une présentation mise en page.

    2. skill-creator, le skill qui crée des skills

    Il pose les questions utiles, rédige le SKILL.md, aide à le modifier et à mesurer s'il se déclenche comme prévu. Il figure dans le dépôt officiel d'Anthropic.

    3. Les skills de partenaires

    Notion, Figma, Canva ou Atlassian publient des skills qui apprennent à Claude à travailler avec leurs outils. Ils s'installent depuis le répertoire de skills de Claude, comme ceux d'Anthropic.

    4. Un skill de charte éditoriale

    Votre ton, vos mots interdits, la façon d'écrire les chiffres, deux textes de référence dans references/. C'est un bon premier skill pour une équipe, parce que la charte s'applique à tout ce qui s'écrit.

    ---
name: charte-editoriale
description: "Applique la charte éditoriale de l'entreprise à tout texte rédigé ou relu. À utiliser pour un e-mail, un post, une page web ou une relecture."
---

    6 skills SEO à créer

    Pour ces skills, Claude doit accéder aux données : les fichiers du site, un crawler, la Search Console. Ces accès passent par des connecteurs MCP, comme le MCP Screaming Frog pour les crawls. Le skill, lui, porte la méthode. D'autres usages de Claude en référencement sont détaillés dans Claude pour le SEO.

    5. Contrôle des balises title et meta

    Le point de départ évident : la tâche est mécanique, se vérifie en un coup d'œil et devient impossible à tenir à jour à la main sur plusieurs centaines de pages. L'exemple complet est plus haut. Le garde-fou : Claude propose, vous relisez, car une balise est ce que voit le visiteur dans les résultats de recherche.

    6. Audit du maillage interne

    Extraire la structure des liens, repérer les pages orphelines et trop profondes, proposer trois liens entrants par page prioritaire avec leur ancre. La règle que j'impose dans mes consignes : aucune ancre générique, toute ancre doit décrire la page cible.

    ---
name: audit-maillage-interne
description: "Analyse le maillage interne à partir d'un crawl, repère les pages orphelines ou trop profondes et propose des liens avec leur ancre. À utiliser pour un audit de liens internes."
---

    7. Données structurées JSON-LD

    Générer le balisage d'un catalogue ou d'un ensemble d'articles, puis valider la syntaxe. Règle absolue : le balisage reflète ce qui est visible sur la page, sans compléter une information manquante par une valeur plausible.

    ---
name: donnees-structurees
description: "Génère le balisage JSON-LD d'une page à partir de son contenu visible, sans inventer de donnée absente. À utiliser pour ajouter ou corriger des données structurées."
---

    8. Plan de redirections de migration

    Rapprocher chaque ancienne URL de son équivalent, signaler les adresses sans correspondance évidente au lieu de trancher, générer le fichier en évitant chaînes et boucles. Ce skill gagne à rester manuel : dans Claude Code, ajoutez la ligne ci-dessous.

    ---
name: plan-redirections
description: "Établit le plan de redirections 301 d'une migration, une ancienne URL vers une destination précise. À utiliser lors d'une refonte ou d'un changement d'URL."
disable-model-invocation: true
---

    9. Rapport mensuel Search Console

    Comparer deux périodes, isoler les décrochages, croiser avec les modifications faites entre-temps, conclure par trois actions. Précaution de méthode à inscrire dans le skill : comparer des périodes d'au moins 28 jours, une variation sur une semaine ne veut rien dire.

    ---
name: rapport-search-console
description: "Compare deux périodes de données Search Console, isole les pages et requêtes en baisse et propose trois actions. À utiliser pour un rapport de suivi SEO mensuel."
---

    10. Contrôle avant publication

    Longueur des balises, hiérarchie des titres, liens internes valides, attributs alt, affirmations sans source. Une relecture technique systématique, qui ne remplace pas la relecture éditoriale : un texte peut passer tous les contrôles et rester mauvais.

    ---
name: controle-avant-publication
description: "Vérifie une page avant sa mise en ligne : balises, titres, liens internes, attributs alt et affirmations sans source. À utiliser avant de publier un article ou une page."
---

    Limites et sécurité des Claude Skills

    Un skill n'est pas un simple texte : il peut contenir des scripts et orienter les outils que Claude utilise. Anthropic recommande de le traiter comme l'installation d'un logiciel.

    • N'installez que des skills de confiance, les vôtres ou ceux d'Anthropic. Un skill malveillant peut pousser Claude à exécuter du code ou à transmettre des données vers l'extérieur.
    • Lisez tout avant d'installer un skill trouvé en ligne : SKILL.md, scripts, ressources. Méfiez-vous des appels réseau inattendus et des skills qui vont chercher des consignes sur une URL externe, dont le contenu peut changer après votre vérification.
    • Pas de synchronisation entre l'application, Claude Code et l'API : chaque surface a sa copie, à tenir à jour.
    • Le déclenchement dépend de la description. Trop vague, Claude ignore le skill ; trop large, il le charge à tort. Deux skills aux descriptions proches se gênent.
    • Chaque skill occupe un peu de contexte en permanence, environ 100 tokens de métadonnées : cinquante skills représentent déjà quelque 5 000 tokens.
    • Côté API, pas d'accès à Internet ni d'installation de paquets, et les skills ne sont pas couverts par les accords de conservation zéro des données.
    • En entreprise, les organisations Enterprise peuvent activer une analyse du contenu des skills importés dans Claude et dans Cowork.

    Les garde-fous à écrire dans vos skills

    Quatre règles, apprises en cassant des choses avec mes propres chaînes SEO : une modification par page plutôt qu'un traitement de masse ; un projet versionné avant que Claude touche à un fichier ; une relecture humaine avant toute mise en production ; un modèle qui signale les cas ambigus au lieu de trancher. Et aucune de mes chaînes ne supprime quoi que ce soit : ces gestes-là se font à la main.

    Si vous voulez des skills métier conçus, testés sur vos dossiers et livrés avec ces garde-fous, c'est ce que je fais en mission d'automatisation IA.

    Questions fréquentes

    C'est quoi un skill Claude ?

    Un skill Claude est un dossier qui contient un fichier SKILL.md (un nom, une description et des instructions), parfois accompagné de fichiers de référence et de scripts. Claude lit la description en permanence et charge le reste seulement quand une demande y correspond. Il sert à transmettre une méthode que vous ne voulez plus répéter à chaque conversation.

    Les Claude Skills sont-ils gratuits ?

    Oui. Selon le centre d'aide d'Anthropic, les skills fonctionnent sur toutes les formules, gratuite comprise, à condition d'activer l'exécution de code et la création de fichiers. Créer un skill ne coûte rien : c'est un fichier texte. Son utilisation consomme simplement le quota de votre formule, comme n'importe quelle demande.

    Comment ajouter un skill à Claude ?

    Dans l'application, compressez le dossier du skill en ZIP, ouvrez Personnaliser > Compétences, cliquez sur +, Créer une compétence, puis Télécharger une compétence. Dans Claude Code, copiez le dossier dans ~/.claude/skills/ ou dans le dossier .claude/skills/ du projet. Par l'API, envoyez-le par les endpoints /v1/skills.

    Où trouver des skills pour Claude ?

    Dans le répertoire intégré à Claude, qui regroupe les skills d'Anthropic et de partenaires, et dans le dépôt GitHub officiel anthropics/skills. Des catalogues communautaires en recensent des milliers, de qualité inégale : lisez chaque fichier avant de l'installer. Les skills les plus utiles restent souvent ceux que vous écrivez pour votre propre méthode.

    Quelle différence entre un skill et un MCP ?

    Un serveur MCP donne à Claude l'accès à un outil ou à des données, par exemple la Search Console. Un skill lui apprend une méthode : quelles données regarder, quelles règles appliquer, quel résultat rendre. Les deux se complètent : le MCP apporte la donnée, le skill dit quoi en faire.

    Quelle différence entre les skills et les projets Claude ?

    Un projet regroupe des documents et des consignes disponibles dans toutes les conversations de ce projet. Un skill contient une procédure, chargée seulement quand la demande y correspond, dans n'importe quelle conversation. Le projet dit à Claude ce qu'il doit savoir, le skill lui dit comment faire.

    Les skills Claude fonctionnent-ils avec d'autres outils que Claude ?

    En grande partie, oui. Anthropic a publié le format en standard ouvert, Agent Skills, en décembre 2025, et des outils comme Cursor, GitHub Copilot, Gemini CLI ou Codex d'OpenAI l'ont adopté. Un skill qui s'en tient aux champs standard a donc de bonnes chances de fonctionner ailleurs, mais testez-le dans chaque outil.

    Pourquoi Claude n'utilise-t-il pas mon skill ?

    Le plus souvent, la description ne contient pas les mots de votre demande ou ne dit pas quand utiliser le skill. Vérifiez aussi que l'exécution de code est activée et que le skill est actif dans Personnaliser > Compétences. Dans Claude Code, la commande /skills liste les skills chargés et /nom-du-skill force son lancement.
