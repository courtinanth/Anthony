Je commence par la définition, puis les prix réels, la question du français, un tuto pour votre premier workflow, le comparatif avec Make et Zapier, et les limites que je constate quand j'installe l'outil chez des clients.

n8n, c'est quoi ?

n8n est une plateforme d'automatisation de workflows : elle relie vos applications entre elles et fait circuler les données de l'une à l'autre, sans que vous ayez à écrire un programme. Vous dessinez l'enchaînement sur un canevas, chaque étape est un nœud, et n8n l'exécute à votre place, à heure fixe ou à chaque événement.

Le nom se prononce « n-eight-n » et contracte « nodemation », pour automatisation par nœuds. L'outil a été créé par Jan Oberhauser et publié en 2019 ; l'entreprise est basée à Berlin.

Comment fonctionne un workflow n8n

Tout workflow suit la même logique en trois temps :

  • Le déclencheur (trigger) lance le workflow : une heure fixe, un formulaire envoyé, un e-mail reçu, un appel webhook venu d'une autre application.
  • Les traitements filtrent, transforment ou trient les données, prennent une décision avec une condition, ou appellent un modèle d'IA.
  • Les actions écrivent le résultat quelque part : une ligne dans un tableur, une fiche dans le CRM, un e-mail, un message Slack.

Exemple concret : quand un prospect remplit votre formulaire de contact, n8n vérifie que le message n'est pas vide, ajoute une ligne dans Google Sheets, puis vous envoie un e-mail récapitulatif. Quatre nœuds, aucune ligne de code. C'est exactement le workflow du tuto plus bas.

Ce qui distingue n8n de Zapier et Make

  • Il s'installe chez vous. Le code est publié sur GitHub et l'édition Community tourne sur votre serveur : vos données ne transitent par aucun service tiers.
  • Il facture l'exécution, pas l'étape. n8n définit une exécution comme un passage complet du workflow, quel que soit le nombre de nœuds ou la quantité de données traitées. Un workflow de vingt nœuds compte pour une seule exécution.
  • Il accepte du code. Le nœud Code exécute du JavaScript ou du Python quand aucun nœud ne fait exactement ce qu'il faut, et le nœud HTTP Request appelle n'importe quelle API.
  • Il est pensé pour l'IA. Nœud AI Agent, connexion aux modèles de langage, client et déclencheur MCP : n8n sert souvent de base pour créer un agent IA ou pour brancher un serveur MCP sur vos outils.

L'édition Community : ce qui est inclus, ce qui manque

La documentation officielle présente l'édition Community comme la version gratuite qui contient presque toutes les fonctions de n8n. Vous avez tous les nœuds et toutes les intégrations, le nœud Code, les agents IA, des workflows et des exécutions sans plafond : la seule limite est la puissance de votre serveur.

Ce qui manque concerne surtout le travail en équipe et la gouvernance :

  • le partage de workflows et d'identifiants entre utilisateurs (seuls le propriétaire de l'instance et l'auteur y accèdent) ;
  • les projets, les environnements et la gestion de versions avec Git ;
  • la connexion unique SSO (SAML, LDAP) ;
  • les coffres de secrets externes et l'envoi des journaux vers un outil de supervision.

En enregistrant gratuitement votre instance avec votre adresse e-mail (édition Registered Community), vous débloquez en plus les dossiers, le débogage dans l'éditeur et les données d'exécution personnalisées.

La licence : ce que le gratuit autorise vraiment

n8n n'est pas un logiciel libre au sens strict. Il est distribué sous une licence maison, la Sustainable Use License : le code est lisible, l'usage est encadré. La FAQ officielle résume la règle ainsi : si les workflows ne sont créés ou modifiés que par vous ou par des personnes de votre organisation, l'usage est gratuit.

Ce que vous pouvez faire gratuitement :

  • faire tourner n8n pour votre entreprise, vos projets personnels ou votre apprentissage ;
  • construire des automatisations pour vos clients sur votre instance, tant qu'ils ne peuvent ni les créer ni les modifier ;
  • facturer la création, la maintenance, la formation et le conseil autour de n8n.

Ce qui est interdit sans licence commerciale :

  • héberger n8n comme un service où vos clients construisent leurs propres workflows ;
  • revendre n8n en marque blanche, ou forker son code pour lancer votre propre outil d'automatisation ;
  • activer les fonctions réservées aux offres payantes sans la clé de licence correspondante.

Le vrai coût de la version gratuite

Gratuit ne veut pas dire sans coût. Il vous faut un serveur, quelques euros par mois pour un petit serveur virtuel, et surtout du temps : installer, sauvegarder, mettre à jour. n8n l'écrit lui-même dans sa documentation : l'auto-hébergement est recommandé aux utilisateurs experts, parce qu'une erreur peut entraîner une perte de données, une faille de sécurité ou une interruption de service.

Ce n'est pas théorique. En janvier 2026, une faille notée 10 sur 10 (CVE-2026-21858) permettait d'attaquer des instances auto-hébergées non mises à jour qui exposaient certains formulaires publics. Les instances à jour n'étaient pas concernées. Si personne dans votre équipe ne suit les mises à jour, le cloud payant vous coûtera moins cher qu'un incident.

Combien d'exécutions vous faut-il ?

n8n en français : l'interface est-elle traduite ?

Non. L'éditeur de n8n est officiellement disponible en anglais seulement, tout comme sa documentation. Une variable d'environnement, N8N_DEFAULT_LOCALE, permet d'afficher une autre langue sur une instance auto-hébergée, mais aucun pack français officiel n'est fourni et les textes non traduits retombent sur l'anglais. En mai 2026, une discussion du forum officiel confirmait encore que seule la version anglaise était disponible.

En pratique, ce n'est pas bloquant. Vos workflows traitent du contenu en français sans difficulté (e-mails, formulaires, textes générés par IA), et une dizaine de termes suffit pour lire l'interface :

Tuto n8n : votre premier workflow pas à pas

Objectif : un formulaire de contact qui enregistre chaque demande dans Google Sheets et vous prévient par e-mail. C'est le cas d'usage le plus courant, et il couvre les quatre gestes de base : déclencher, lire une donnée, décider, agir.

Étape 1 : installer n8n ou ouvrir un compte cloud

Deux options. Sans rien installer : créez un essai gratuit sur n8n.io, vous arrivez directement dans l'éditeur. En local et gratuitement : installez Docker Desktop, puis lancez la commande d'installation officielle dans un terminal.

curl -fsSL https://get.n8n.io | sh

Le script vérifie que Docker tourne, crée un dossier n8n avec sa configuration, télécharge l'outil et le démarre. Ouvrez ensuite http://localhost:5678 et créez le compte propriétaire de l'instance. Si vous préférez lancer le conteneur vous-même :

docker volume create n8n_data

docker run -it --rm \
 --name n8n \
 -p 5678:5678 \
 -e GENERIC_TIMEZONE="Europe/Paris" \
 -e TZ="Europe/Paris" \
 -e N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true \
 -v n8n_data:/home/node/.n8n \
 n8nio/n8n

Oubliez npx n8n

La commande npx n8n que vous croiserez dans d'anciens tutos est dépréciée. n8n annonce qu'à partir de sa version 3.0, prévue pour octobre 2026, l'outil ne sera plus distribué que via Docker.

Étape 2 : créer le workflow et son déclencheur

  1. Cliquez sur Create Workflow (ou Start from Scratch), puis sur Add first step.
  2. Cherchez « Form » et choisissez le déclencheur n8n Form Trigger. Renommez le nœud « Formulaire » en double-cliquant sur son titre.
  3. Donnez un titre au formulaire et ajoutez trois champs : Nom, Email et Message.
  4. Cliquez sur Execute step : n8n ouvre le formulaire de test. Remplissez-le une fois, la sortie du nœud affiche vos données.

Étape 3 : ajouter une condition

Ajoutez un nœud If après le formulaire pour écarter les envois vides. Faites glisser le champ Message depuis le panneau de gauche, choisissez la comparaison String > is not empty. Seule la branche true continue vers la suite.

Étape 4 : enregistrer la demande dans Google Sheets

  1. Préparez une feuille Google Sheets avec trois colonnes : Nom, Email, Message.
  2. Sur la branche true, ajoutez un nœud Google Sheets avec l'opération Append Row (ajouter une ligne).
  3. Dans Credential, choisissez Create new credential. Sur n8n Cloud, la connexion à Google se fait en vous identifiant directement. En auto-hébergé, il faut d'abord créer des identifiants OAuth dans la console Google Cloud.
  4. Sélectionnez le fichier et la feuille, puis faites glisser chaque champ du formulaire vers la colonne correspondante.

Étape 5 : vous prévenir par e-mail

Après Google Sheets, ajoutez un nœud Gmail (opération Send) ou Send Email si vous passez par un serveur SMTP. Dans le corps du message, des expressions reprennent les réponses du formulaire :

Nouvelle demande de {{ $('Formulaire').item.json.Nom }}
Adresse : {{ $('Formulaire').item.json.Email }}
Message : {{ $('Formulaire').item.json.Message }}

Étape 6 : tester, puis publier

  1. Cliquez sur Execute workflow, remplissez le formulaire de test et vérifiez chaque nœud : une ligne dans le tableur, un e-mail reçu.
  2. Utilisez Pin data sur le déclencheur pour rejouer les mêmes données sans remplir le formulaire à chaque essai.
  3. Cliquez sur Publish : le formulaire passe sur son adresse de production (Production URL), à intégrer sur votre site ou à partager. Sur les versions plus anciennes de n8n, ce bouton s'appelle Active.
  4. Surveillez l'onglet Executions les premiers jours : chaque échec y est détaillé, nœud par nœud. C'est la partie que tout le monde néglige, et celle qui coûte le plus cher ensuite.

Pour aller plus loin, la bibliothèque officielle propose plus de 10 000 modèles de workflows prêts à importer. Partez d'un modèle proche de votre besoin plutôt que d'une page blanche.

Avant de construire, listez

Notez pendant une semaine tout ce que vous faites plus de trois fois. Cette liste vous dit quoi automatiser avant de vous demander avec quel outil. Une tâche pénible mais trimestrielle ne mérite pas d'être automatisée ; une tâche banale mais quotidienne se rembourse vite. J'en donne des cas concrets dans mes exemples d'automatisation IA.

n8n vs Make : les différences qui comptent

Make est le concurrent le plus proche : même logique visuelle, même public. La différence se joue sur le comptage. Make consomme un crédit par module exécuté : un scénario de 8 modules lancé 1 000 fois consomme environ 8 000 crédits. Le même workflow dans n8n consomme 1 000 exécutions. Plus vos scénarios sont longs, plus n8n devient avantageux.

Make garde deux atouts : une offre gratuite hébergée, pratique pour tester sans serveur, et une interface très visuelle que les profils non techniques prennent vite en main. n8n l'emporte dès que la confidentialité des données compte, que les volumes montent, ou que vous voulez du code au milieu du workflow.

Mon verdict selon votre situation

  • Données personnelles ou sensibles : n8n auto-hébergé, le seul des trois qui garde tout chez vous.
  • Scénarios longs ou gros volumes : n8n, en cloud ou en auto-hébergé, grâce au comptage à l'exécution.
  • Équipe non technique, petits volumes, envie de démarrer en dix minutes : Zapier, puis Make si la facture monte.
  • Tester gratuitement sans serveur : l'offre Free de Make ou l'essai de n8n Cloud.

Les limites de n8n

  • L'anglais partout. Interface, documentation, messages d'erreur : il faut accepter de travailler en anglais.
  • L'auto-hébergement est un métier. Sauvegardes, mises à jour, sécurité : la gratuité se paie en temps, et la faille de janvier 2026 a montré ce que coûte une instance oubliée.
  • La lisibilité au-delà de 30 ou 40 nœuds. Un workflow de dix nœuds est plus clair qu'un script. Un workflow de cinquante nœuds avec des branches imbriquées devient difficile à relire, même pour son auteur.
  • Le versionnage réservé aux offres hautes. La gestion de versions avec Git et les environnements de test sont inclus dans Business et Enterprise, pas dans Starter, Pro ni Community.
  • Une licence qui encadre la revente. Impossible de proposer n8n comme service à vos clients sans licence commerciale.
  • Le coût réel, c'est le temps. L'abonnement pèse rarement le plus lourd : concevoir les workflows, les corriger quand une application change son API et former les utilisateurs coûte davantage.

Quand je recommande n8n, et quand je code plutôt

J'ai installé n8n chez des clients et il rend de vrais services. Aujourd'hui pourtant, je livre la plupart de mes automatisations sous forme de programmes écrits avec Claude Code : décrire un besoin en français et obtenir un programme versionné, testé et relisible est devenu accessible (voir comment installer Claude Code). L'argument principal du no-code, se passer de compétences techniques, s'est affaibli.

Ma règle de décision, en une phrase

Si l'automatisation déplace des données entre deux applications qui ont déjà un connecteur, n8n est plus rapide à mettre en place. Dès qu'il y a des règles métier, des exceptions et un besoin de fiabilité dans la durée, un programme versionné coûte moins cher à faire vivre.

Je recommande n8n sans hésiter dans quatre cas :

  • Une équipe non technique qui veut garder la main. Modifier un workflow visuel est à la portée de tous, modifier un script non.
  • Un besoin d'intégration pur. Relier un formulaire, un CRM et une messagerie ne mérite pas un développement.
  • Une contrainte forte de confidentialité. L'auto-hébergement est un argument que ni Make ni Zapier n'offrent.
  • Un prototype. Valider qu'un process automatisé apporte de la valeur avant d'investir dans du sur-mesure.

L'approche mixte marche souvent le mieux : prototyper dans n8n, mesurer le gain réel, puis réécrire en code ce qui devient critique. C'est la démarche que je suis dans mes missions d'automatisation IA sur mesure, et que je détaille dans mon guide sur l'automatisation des processus.

Questions fréquentes

n8n est-il gratuit ?

Oui, si vous l'hébergez vous-même : l'édition Community est gratuite, sans quota d'exécutions ni limite de workflows, et vous ne payez que votre serveur. La version cloud, hébergée par n8n, est payante à partir de 20 € par mois en facturation annuelle, avec un essai gratuit sans carte bancaire.

n8n, c'est quoi ?

n8n est une plateforme d'automatisation de workflows qui relie des applications entre elles sans écrire de code. Vous assemblez des nœuds sur un canevas visuel : un déclencheur, des traitements, des actions. L'outil, créé à Berlin et publié en 2019, tourne dans le cloud ou sur votre propre serveur.

Combien coûte n8n ?

En cloud, l'offre Starter coûte 24 € par mois (20 € en annuel) pour 2 500 exécutions et l'offre Pro 60 € par mois (50 € en annuel) pour 10 000 exécutions. L'offre Business, auto-hébergée, coûte 667 € par mois en annuel pour 40 000 exécutions. L'édition Community auto-hébergée est gratuite. Tarifs relevés sur n8n.io le 7 octobre 2026.

n8n existe-t-il en français ?

Non, l'interface officielle de n8n est en anglais, comme sa documentation. Une variable d'environnement permet de changer la langue d'une instance auto-hébergée, mais aucune traduction française officielle n'est fournie. Vos workflows traitent en revanche du contenu en français sans difficulté.

Est-il possible d'utiliser n8n gratuitement en entreprise ?

Oui. La licence de n8n autorise l'usage gratuit de l'édition Community pour les besoins internes d'une entreprise, y compris pour automatiser des services rendus à vos clients, tant qu'ils ne créent ni ne modifient eux-mêmes les workflows. Elle interdit en revanche de revendre n8n comme service d'automatisation ou en marque blanche.

n8n ou Make : lequel choisir ?

Choisissez n8n si vos scénarios sont longs, si vos volumes montent ou si vos données doivent rester chez vous : il compte une exécution par passage complet, quand Make compte chaque module. Choisissez Make pour démarrer gratuitement sans serveur, avec une interface très visuelle. À volume égal, l'écart de prix grandit avec le nombre d'étapes.

Faut-il savoir coder pour utiliser n8n ?

Non pour les workflows courants : les nœuds se configurent dans des formulaires et les données se glissent d'une étape à l'autre. Quelques notions aident vite, comme les expressions entre doubles accolades ou le format JSON. L'installation en auto-hébergement demande en revanche d'être à l'aise avec un terminal et Docker.

Comment installer n8n gratuitement ?

Le script configure et démarre n8n, accessible ensuite à l'adresse http://localhost:5678. Pour un usage en production, prévoyez un vrai serveur, une base PostgreSQL et un suivi régulier des mises à jour.

Résumé IA

n8n est une plateforme d'automatisation qui relie des applications par des workflows visuels faits de nœuds. Elle est gratuite en auto-hébergement (édition Community, sans quota d'exécutions) et payante en cloud dès 20 € par mois en annuel. L'interface est en anglais. Face à Make et Zapier, n8n compte une exécution par workflow complet, pas par étape.
