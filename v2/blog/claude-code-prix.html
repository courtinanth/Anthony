Claude Code prix : gratuit ou payant ? Formules, API et coût réel

Il n'existe pas d'abonnement « Claude Code » séparé. Vous payez un accès à Claude, et Claude Code vient avec, dans le terminal, dans VS Code, dans JetBrains et dans l'application de bureau. La seule vraie décision est le niveau d'usage dont vous avez besoin.

Pro : le ticket d'entrée

Pro est le premier palier qui débloque Claude Code. L'engagement annuel revient à 200 $ réglés d'avance, soit 40 $ d'économie sur douze mois. Pour un indépendant qui code quelques heures par semaine, c'est le point de départ raisonnable. Attention : l'abonnement Pro ne comprend pas l'usage de l'API par la Console, qui se paie à part.

Max : pour un usage quotidien

Max existe en deux crans, 100 $ et 200 $ par mois, pour cinq et vingt fois l'usage de Pro, avec un accès prioritaire aux nouveautés. Il n'y a pas de tarif annuel. C'est la formule que je conseille dès que Claude Code devient un outil de travail quotidien plutôt qu'un appoint.

Team et Enterprise : pour une équipe

Team se compte en sièges, de 2 à 150, et chaque siège donne accès à Claude Code. Le mélange des deux types de sièges est rentable : quelques sièges Premium pour ceux qui codent toute la journée, des sièges Standard pour ceux qui rédigent ou analysent. Enterprise fonctionne autrement : un siège à 20 $ par mois en annuel, auquel s'ajoute la consommation réelle au tarif de l'API. Une organisation qui budgète Enterprise comme une ligne fixe se trompe : la consommation se modélise à côté.

Claude Code gratuit : ce qui est possible, et ce qui ne l'est pas

La formule gratuite de Claude donne accès au chat sur le web, le mobile et l'application de bureau, avec un volume limité. Elle ne donne pas accès à Claude Code : dans l'application de bureau, un clic sur l'onglet Code propose de passer à une formule payante, et la documentation officielle l'écrit noir sur blanc. Si votre besoin est surtout de discuter avec Claude, mon article sur Claude AI gratuit détaille ce que permet la formule gratuite.

Quatre portes restent ouvertes pour utiliser Claude Code sans payer, chacune avec ses limites.

1. Une invitation de 7 jours (guest pass)

Les abonnés Pro et Max éligibles disposent d'un nombre limité d'invitations. La personne invitée reçoit sept jours gratuits de la formule Pro, Claude Code compris. Condition : ne jamais avoir eu d'abonnement payant à Claude. Côté abonné, la commande /passes dans Claude Code affiche les invitations disponibles et le lien à partager. C'est le moyen le plus simple de tester l'outil sur un vrai projet.

2. Le crédit API offert aux nouveaux comptes

Anthropic indique que les nouveaux utilisateurs de l'API reçoivent « un petit montant de crédits gratuits » pour tester. Le montant n'est pas publié. Une fois Claude Code connecté à ce compte Console, ce crédit suffit pour quelques sessions d'essai, pas pour travailler.

3. Le programme Claude for Open Source

Anthropic offre six mois de Max 20x aux contributeurs open source qui remplissent l'un de ses critères : maintenir une bibliothèque dont dépendent au moins 500 dépôts ou 100 paquets, ou qui cumule 200 000 téléchargements par mois ; faire partie de l'équipe principale d'un projet reconnu (CPython, Node.js, Kubernetes, noyau Linux…) ; avoir fait fusionner au moins 100 pull requests dans des dépôts tiers en un an. À la fin des six mois, l'abonnement offert s'arrête.

4. Claude Code avec un modèle open source (Ollama)

C'est la méthode qui circule sous le titre « Claude Code gratuit et illimité ». Ollama sait faire tourner Claude Code avec des modèles open source installés sur votre machine : la commande ollama launch claude s'en charge, et Ollama conseille une fenêtre de contexte de 64 000 tokens ou plus. Le coût est nul, mais ce n'est plus Claude qui travaille : vous gardez l'interface de Claude Code avec un autre modèle, nettement moins capable sur les tâches longues, et il faut une machine puissante. Utile pour apprendre l'outil, pas pour juger ce qu'il vaut.

Méfiez-vous des « clés gratuites »

Les clés API partagées sur des forums ou les extensions non officielles qui promettent Claude Code gratuit font transiter votre code par un intermédiaire inconnu. Sur un projet client, c'est un risque que rien ne justifie.

Quel est le prix de Claude Code à l'API ?

Avec un compte Claude Console, Claude Code se facture au token consommé, sans abonnement ni minimum. Voici les tarifs des modèles actuels, en dollars par million de tokens, relevés le 7 octobre 2026 :

ModèleEntréeSortieLecture de cachePour quoi faire
Claude Fable 5.110 $50 $0,25 $Le plus cher de la gamme, pour les cas les plus durs
Claude Opus 5.54 $20 $0,20 $Raisonnement complexe, décisions d'architecture
Claude Sonnet 5.52 $10 $0,20 $La plupart des tâches de code
Claude Haiku 4.51 $5 $0,10 $Tâches simples, sous-agents

Trois mécanismes font varier la facture bien plus que la grille elle-même.

Le cache. Claude Code renvoie toute la conversation à chaque requête, mais il s'appuie automatiquement sur le cache : la partie déjà vue se relit à un dixième du prix d'entrée (un vingtième sur Opus 5.5). L'écriture en cache coûte 1,25 fois le prix d'entrée pour une conservation de cinq minutes, deux fois pour une heure. C'est pour cela qu'une pause longue coûte cher : la première requête après expiration du cache repaie tout le contexte.

Le choix du modèle. Entre Haiku et Opus 5.5, l'écart est d'un facteur quatre. La documentation de Claude Code le dit sans détour : Sonnet suffit pour la plupart des tâches, Opus est à réserver aux décisions d'architecture et au raisonnement en plusieurs étapes. La commande /model change de modèle en cours de session.

Le raisonnement. Les tokens de réflexion sont facturés comme des tokens de sortie. Sur Opus 5.5, Sonnet 5.5 et Fable, la réflexion ne se désactive pas ; vous pouvez baisser le niveau d'effort avec /effort.

Le piège du tokeniseur

Comparer deux modèles au prix du million de tokens ne suffit pas. Depuis Claude 4.7, les modèles utilisent un tokeniseur qui découpe le texte plus finement : à texte identique, il produit environ 30 % de tokens en plus, selon la documentation d'Anthropic. Un modèle récent affiché au même tarif qu'un ancien consomme donc davantage d'unités pour le même travail. La seule comparaison sérieuse se fait sur vos propres contenus.

Ce qui peut s'ajouter

  • Le mode rapide d'Opus 5.5 double le tarif : 8 $ en entrée et 40 $ en sortie par million de tokens.
  • L'inférence limitée aux États-Unis, pour des raisons de conformité, applique un coefficient de 1,1 sur tous les postes.
  • La recherche web par l'API coûte 10 $ les 1 000 recherches, en plus des tokens des pages rapportées.

Combien coûte vraiment Claude Code par mois ?

La documentation de Claude Code donne un repère rare, mesuré sur les déploiements en entreprise facturés à l'usage : environ 13 $ par développeur et par jour actif, et 150 à 250 $ par développeur et par mois. Pour 90 % des utilisateurs, la dépense reste sous les 30 $ par jour actif.

Mis en face des abonnements, le calcul est parlant. Un développeur qui travaille avec Claude Code tous les jours consomme à l'API à peu près le prix d'un abonnement Max. L'abonnement apporte alors la prévisibilité, et couvre en prime Claude dans le navigateur. À l'inverse, un usage de quelques heures par semaine reste souvent sous les 20 $ de Pro.

Pour suivre votre propre consommation, la commande /usage affiche dans une session le coût estimé (en compte API) ou vos jauges de limites (en abonnement), avec la part due aux skills, aux sous-agents et aux serveurs MCP.

Chiffrez votre cas : entrez votre consommation mensuelle, ou votre nombre de jours d'usage, et l'outil vous dit quelle formule revient le moins cher.

Abonnement ou API : comment choisir

La bascule se calcule, elle ne se devine pas. Voici la méthode que j'applique.

  1. Relevez votre consommation réelle sur un mois : /usage en session, ou la page Usage de la Console si vous êtes à l'API.
  2. Convertissez-la en coût API avec la grille ci-dessus, cache compris, ou avec l'outil.
  3. Comparez aux paliers de 20 $, 100 $ et 200 $. Sous le palier qui vous suffit, l'abonnement gagne, et pas seulement sur le prix : il apporte un montant fixe et couvre Claude dans le navigateur.

Deux mécaniques de l'abonnement sont à connaître avant de trancher. D'abord, les limites ne forment pas un compteur mensuel : elles se réinitialisent par tranches de cinq heures, avec en plus un plafond hebdomadaire. Une grosse journée peut donc vous arrêter quelques heures alors que votre mois est loin d'être entamé. Ensuite, l'usage de Claude et celui de Claude Code puisent dans le même compteur : une longue session de rédaction dans le navigateur réduit ce qu'il vous reste pour coder. Une fois la limite atteinte, vous pouvez attendre la remise à zéro, ou activer les crédits d'usage, facturés au tarif de l'API.

Trois signaux poussent vers l'API, quel que soit le calcul :

  • Claude Code tourne dans des scripts ou une chaîne d'intégration continue, sans personne devant l'écran.
  • Vous voulez un plafond de dépense par espace de travail, réglable dans la Console.
  • Vous êtes plusieurs et chacun a un usage très différent, ce qui se modélise mieux au token. Chiffrez aussi Team avant de multiplier les abonnements individuels.

Une clé API oubliée change la facture

Si la variable ANTHROPIC_API_KEY est définie sur votre machine, Claude Code l'utilise à la place de votre abonnement, une fois que vous l'avez acceptée : l'usage part alors en facturation API. Vérifiez la méthode active avec /status. La marche à suivre est dans mon tuto pour installer Claude Code.

Réduire la facture de Claude Code

Le coût suit la taille du contexte : plus Claude Code relit de choses, plus vous payez, en dollars à l'API comme en limites sur un abonnement.

  • Une session par tâche. /clear repart d'un contexte vide quand vous changez de sujet ; une session ouverte toute la journée renvoie tout son historique à chaque échange.
  • Le bon modèle. Sonnet par défaut, Opus quand la tâche le justifie, Haiku pour les sous-agents simples.
  • Un CLAUDE.md court. La documentation conseille de rester sous 200 lignes et de déplacer les procédures spécialisées dans des skills, chargées seulement quand elles servent. Le mode d'emploi est dans Claude Skills.
  • Moins de serveurs MCP actifs. Désactivez avec /mcp ceux qui ne servent pas ; un outil en ligne de commande coûte moins de contexte. Voir c'est quoi un serveur MCP.
  • Des demandes précises. « Ajoute une validation dans la fonction de connexion de auth.ts » coûte bien moins que « améliore ce projet », qui déclenche une exploration de tout le dépôt.
  • Le mode Plan avant un gros chantier : l'agent propose une approche avant de modifier, ce qui évite de payer un travail à refaire.

Ce que je paie, moi

Je travaille avec un abonnement pour l'usage quotidien, dans le terminal comme dans le navigateur, et j'ouvre l'API pour tout ce qui est automatisé : les pipelines de contenu, les scripts d'audit, les traitements en série sur des milliers d'URL.

Cette séparation a un mérite pratique. L'abonnement couvre la partie imprévisible, celle où je discute avec le modèle et où je ne veux pas surveiller un compteur. L'API couvre la partie industrielle, celle que je peux mesurer, mettre en cache et passer en traitement par lots. Le budget devient lisible, et surtout optimisable. C'est ce type de chaîne que je mets en place en mission d'automatisation IA.

Un dernier conseil, valable quel que soit votre choix : posez une limite de dépense sur votre compte API dès le premier jour. Un agent mal cadré qui tourne en boucle peut consommer en une nuit ce que vous aviez prévu pour le mois.

Questions fréquentes

Claude Code est-il gratuit ?

Non. La formule gratuite de Claude n'inclut pas Claude Code. L'outil s'installe gratuitement, mais son usage demande un abonnement Pro, Max, Team ou Enterprise, ou un compte API facturé au token. Les seuls accès gratuits sont l'invitation de 7 jours d'un abonné, le petit crédit API de départ et le programme pour les mainteneurs open source.

Quel est le prix de Claude Code ?

Claude Code n'a pas de tarif propre : il est compris dans les formules payantes de Claude. Comptez 20 $ par mois avec Pro (17 $ en annuel), 100 $ ou 200 $ avec Max, 20 à 125 $ par siège avec Team. À l'API, il se facture au token, par exemple 2 $ en entrée et 10 $ en sortie par million de tokens avec Sonnet 5.5.

Claude Code est-il inclus dans l'abonnement Claude Pro ?

Oui, sans supplément. L'abonnement Pro donne accès à Claude Code dans le terminal, dans VS Code, dans les IDE JetBrains et dans l'application de bureau. L'usage de Claude Code et celui de Claude dans le navigateur partagent les mêmes limites.

Est-il possible d'utiliser Claude Code gratuitement avec Ollama ?

Oui, mais ce n'est plus Claude qui travaille. Ollama fait tourner Claude Code avec des modèles open source installés sur votre machine, par exemple avec la commande ollama launch claude. Le coût est nul, mais ces modèles sont nettement moins capables et demandent un ordinateur puissant.

Combien coûte Claude Code par mois en moyenne ?

Selon la documentation d'Anthropic, l'usage moyen en entreprise revient à environ 13 $ par développeur et par jour actif, et 150 à 250 $ par mois, au tarif de l'API. Pour 90 % des utilisateurs, la dépense reste sous les 30 $ par jour actif. Un usage de quelques heures par semaine coûte bien moins.

Comment fonctionnent les limites d'usage de Claude Code ?

Sur un abonnement, l'usage se réinitialise par tranches de cinq heures, avec en plus un plafond hebdomadaire. Ce compteur est partagé entre Claude dans le navigateur et Claude Code. La commande /usage affiche où vous en êtes et ce qui consomme le plus.

Que se passe-t-il quand j'atteins la limite de mon abonnement ?

Claude Code vous indique l'heure de remise à zéro. Vous pouvez attendre, passer à la formule supérieure, ou activer les crédits d'usage, facturés au tarif de l'API, pour continuer tout de suite. Sur Pro et Max, une limite de dépense mensuelle se règle dans les paramètres de votre compte.

Claude Code est-il moins cher à l'API ou en abonnement ?

Cela dépend du volume. Un usage léger coûte souvent moins de 20 $ par mois à l'API. Un usage quotidien revient à l'API à peu près au prix d'un abonnement Max, qui apporte en plus un montant fixe. L'API garde l'avantage pour les scripts automatisés et le contrôle fin des dépenses.
