C'est quoi Claude Code ?

Claude Code est l'agent de programmation d'Anthropic : il lit les fichiers d'un projet, les modifie, exécute des commandes et vérifie son propre travail. Contrairement à un chatbot qui propose du code à recopier, il agit directement dans votre dossier, avec votre accord selon le mode de permission choisi.

Il existe sous plusieurs formes, qui partagent le même moteur :

  • Claude Code CLI : l'outil en ligne de commande, lancé avec claude dans un terminal. C'est lui que ce tuto installe en premier.
  • L'extension VS Code et le plugin JetBrains : Claude Code dans votre éditeur, avec les modifications affichées en diff.
  • Claude Code desktop : l'onglet Code de l'application de bureau Claude, sans terminal.
  • Claude Code sur le web : des sessions qui tournent dans le cloud, depuis claude.ai/code.

Je l'utilise tous les jours, et pas seulement pour développer : trier des exports, vérifier des redirections, générer des rapports. Si vous découvrez cette façon de travailler, mon article sur le vibe coding en montre les possibilités et les limites.

Installer Claude Code sur Mac (macOS)

Ouvrez l'application Terminal (Cmd + Espace, tapez « Terminal ») et collez :

curl -fsSL https://claude.ai/install.sh | bash

Le programme s'installe dans votre dossier personnel, sans droits administrateur, sur les Mac Intel comme sur les puces Apple. Fermez ensuite la fenêtre, ouvrez-en une nouvelle et vérifiez avec claude --version.

Si vous gérez vos logiciels avec Homebrew :

brew install --cask claude-code

Ce cask suit le canal stable, en général une semaine derrière la dernière version et sans les versions qui ont posé problème. Pour recevoir chaque nouvelle version dès sa sortie, installez claude-code@latest. Dans les deux cas, Homebrew ne met pas Claude Code à jour tout seul : pensez à brew upgrade.

Installer Claude Code sur Linux

Même commande que sur Mac, dans votre terminal :

curl -fsSL https://claude.ai/install.sh | bash

Si vous préférez que les mises à jour passent par le gestionnaire de paquets du système, Anthropic publie des dépôts signés pour apt (Debian, Ubuntu), dnf (Fedora, RHEL) et apk (Alpine). Pour Ubuntu ou Debian, sur le canal stable :

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://downloads.claude.ai/keys/claude-code.asc -o /etc/apt/keyrings/claude-code.asc
echo "deb [signed-by=/etc/apt/keyrings/claude-code.asc] https://downloads.claude.ai/claude-code/apt/stable stable main" | sudo tee /etc/apt/sources.list.d/claude-code.list
sudo apt update
sudo apt install claude-code

Sur une installation neuve, lancez d'abord sudo apt install curl gnupg. Avant de faire confiance à la clé, vérifiez son empreinte avec gpg --show-keys /etc/apt/keyrings/claude-code.asc : elle doit se terminer par BAA929FF1A7ECACE. Alpine demande quelques paquets en plus (bash, curl, libgcc, libstdc++, ripgrep), détaillés dans la documentation officielle.

Installer Claude Code sur Windows (PowerShell, CMD, WinGet)

Claude Code tourne nativement sous Windows 10 (version 1809 et plus) et Windows 11, sans WSL et sans droits administrateur. Ouvrez PowerShell depuis le menu Démarrer et collez :

irm https://claude.ai/install.ps1 | iex

Dans l'invite de commandes classique (CMD), la commande est différente :

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Pour savoir où vous êtes : l'invite affiche PS C:\Users\VotreNom> dans PowerShell, et C:\Users\VotreNom> sans le « PS » dans CMD. Se tromper de commande est une erreur courante sous Windows. Autre voie, plus classique pour un poste géré : winget install Anthropic.ClaudeCode, à mettre à jour avec winget upgrade Anthropic.ClaudeCode.

Installez aussi Git for Windows. Il n'est plus obligatoire : sans lui, Claude Code exécute ses commandes avec PowerShell. Avec lui, l'agent dispose de Git Bash, dont certains de ses outils ont besoin.

Installer Claude Code sous WSL

WSL vous donne un vrai Linux dans Windows. Choisissez-le si vos projets utilisent des outils Linux, ou si vous voulez l'isolation des commandes (sandbox), disponible avec WSL 2 mais pas en natif Windows. Ouvrez votre distribution (Ubuntu, par exemple) et lancez la commande Linux dans ce terminal, pas dans PowerShell :

curl -fsSL https://claude.ai/install.sh | bash

Claude Code s'installe et se lance alors côté Linux. WSL n'a pas besoin de Git for Windows.

Installer Claude Code avec npm

L'ancienne méthode reste disponible sur tous les systèmes, avec Node.js 22 ou plus :

npm install -g @anthropic-ai/claude-code

Le paquet npm installe le même programme natif que l'installeur. N'utilisez jamais sudo npm install -g : c'est une source de problèmes de droits et un risque de sécurité. Pour mettre à jour, préférez npm install -g @anthropic-ai/claude-code@latest à npm update -g, qui peut vous laisser sur une ancienne version.

Vérifier que Claude Code est bien installé

Fermez le terminal qui a servi à l'installation et ouvrez-en un nouveau : l'ancien garde l'ancienne valeur du PATH. Puis :

claude --version

Une installation correcte affiche un numéro de version suivi de « (Claude Code) ». Pour un diagnostic complet (état de l'installation, réglages invalides, dernière mise à jour), lancez :

claude doctor

Avec l'installeur natif, la commande claude se trouve dans ~/.local/bin sur Mac et Linux, et dans %USERPROFILE%\.local\bin sous Windows. Les versions successives sont rangées dans ~/.local/share/claude.

Se connecter à son compte Claude

Placez-vous dans le dossier de votre projet et lancez Claude Code :

cd chemin/vers/votre/projet
claude

Au premier lancement, le navigateur s'ouvre sur la page de connexion. Validez, revenez au terminal : vos identifiants sont enregistrés et vous n'aurez plus à vous reconnecter. Trois types de comptes fonctionnent :

  • Un abonnement Claude Pro, Max, Team ou Enterprise : la voie la plus simple, l'usage est compris dans l'abonnement.
  • Un compte Claude Console : l'usage est facturé au token sur des crédits prépayés. À la première connexion, la Console crée un espace de travail « Claude Code » pour suivre les dépenses.
  • Amazon Bedrock, Google Cloud ou Microsoft Foundry, pour les entreprises qui passent par leur fournisseur cloud.

Si le navigateur ne s'ouvre pas, appuyez sur c pour copier le lien de connexion et collez-le à la main. Depuis WSL, un serveur en SSH ou un conteneur, la page affiche un code à recoller dans le terminal ; si le collage ne passe pas, claude auth login lit ce code directement. Pour changer de compte : /logout puis /login. Pour voir le compte actif : /status.

Une clé d'API oubliée passe avant votre abonnement

Si la variable ANTHROPIC_API_KEY est définie dans votre terminal, Claude Code propose de l'utiliser à la place de la connexion par navigateur. Une vieille clé d'un ancien projet provoque alors des erreurs, ou une facturation à l'API que vous n'attendiez pas. Vérifiez avec /status, et retirez la ligne export ANTHROPIC_API_KEY=… de votre ~/.zshrc ou ~/.bashrc si elle ne vous sert plus.

Premières commandes Claude Code

Une fois connecté, vous parlez à Claude Code en français, comme à un collègue. Commencez par lui faire comprendre le projet avant de lui demander de modifier quoi que ce soit :

que fait ce projet ?
explique-moi l'organisation des dossiers
/init

La commande /init crée un fichier CLAUDE.md à la racine : le contexte du projet, que Claude Code relit à chaque démarrage (à quoi sert le projet, quelles commandes lancer, quelles règles respecter). C'est le réglage le plus rentable de l'outil. Relisez-le et complétez-le : un projet avec un bon fichier de contexte donne des résultats sans commune mesure avec le même projet sans. C'est le principe que je développe dans mon article sur le prompt engineering : ce que vous donnez à lire compte plus que la façon dont vous demandez.

Les modes de permission : ce que Claude Code fait sans vous demander

Un mode de permission fixe ce que l'agent peut faire sans votre accord. Maj + Tab passe d'un mode à l'autre pendant la session.

  • Manual : il demande avant chaque modification de fichier ou commande ; seules les lectures passent sans question. Le bon choix pour débuter ou pour un travail sensible.
  • Accept edits : il modifie les fichiers et lance les commandes de fichiers courantes (créer, copier, déplacer) sans demander.
  • Plan : il analyse et propose un plan sans rien modifier, utile avant un gros changement.
  • Auto : un second modèle examine les actions à votre place et bloque celles qui présentent un risque.

Depuis la version 2.1.283, une session interactive démarre en mode auto, sauf réglage contraire. Si vous débutez, je conseille de passer en Manual les premiers jours et de travailler sur une copie du dossier : vous voyez ce que l'agent va faire avant qu'il le fasse.

Installer l'extension Claude Code pour VS Code

L'extension est la façon la plus confortable d'utiliser Claude Code si le terminal vous rebute : les modifications s'affichent en diff, vous relisez et ajustez le plan avant de l'accepter, et vous citez un fichier avec @. Il faut VS Code 1.94 ou plus récent.

  1. Ouvrez la vue Extensions : Cmd + Maj + X sur Mac, Ctrl + Maj + X sous Windows et Linux.
  2. Cherchez « Claude Code », publié par Anthropic, et cliquez sur Installer. En ligne de commande : code --install-extension anthropic.claude-code.
  3. Ouvrez un fichier, puis cliquez sur l'icône Spark en haut à droite de l'éditeur, ou sur « ✻ Claude Code » dans la barre d'état.
  4. Cliquez sur Sign in et validez la connexion dans le navigateur.

L'extension s'installe aussi dans Cursor et dans les autres éditeurs dérivés de VS Code, depuis leur catalogue ou le registre Open VSX. Point à connaître : elle embarque sa propre copie de Claude Code et n'ajoute pas la commande claude au terminal. Pour l'avoir aussi en ligne de commande, installez le CLI à part. À l'inverse, lancer claude dans le terminal intégré de VS Code installe l'extension automatiquement.

Claude Code dans JetBrains (IntelliJ, PyCharm, WebStorm…)

Le plugin JetBrains fonctionne avec IntelliJ IDEA, PyCharm, WebStorm, PhpStorm, GoLand et Android Studio. Contrairement à l'extension VS Code, il n'embarque pas Claude Code : il lance la commande claude dans le terminal de l'IDE.

  1. Installez le CLI avec l'une des commandes ci-dessus et vérifiez claude --version.
  2. Installez le plugin « Claude Code [Beta] » depuis le Marketplace JetBrains (Settings, puis Plugins), et redémarrez l'IDE.
  3. Lancez claude dans le terminal intégré, ou utilisez Cmd + Échap sur Mac, Ctrl + Échap sous Windows et Linux.

Depuis un terminal externe, la commande /ide connecte la session à l'IDE ouvert. Sous WSL, indiquez dans les réglages du plugin la commande wsl -d Ubuntu -- bash -lic "claude", en remplaçant Ubuntu par le nom de votre distribution.

Claude Code desktop : l'application de bureau

Si vous ne voulez pas de terminal du tout, l'application de bureau Claude contient Claude Code dans son onglet Code. Elle s'installe comme n'importe quel logiciel, sans Node.js ni CLI.

  • macOS : une version universelle, pour les Mac Intel comme pour les puces Apple.
  • Windows : un installeur x64, et un installeur séparé pour les processeurs ARM64.
  • Linux : en bêta, pour Ubuntu 22.04 ou Debian 12 et versions suivantes, par le dépôt apt d'Anthropic (paquet claude-desktop).

Lancez l'application, connectez-vous, cliquez sur l'onglet Code puis sur Select folder pour choisir votre projet. Vous pouvez travailler en local, dans le cloud (la session continue application fermée), sur une machine distante en SSH, ou dans WSL sous Windows. La même application donne accès au chat et à Cowork, l'agent de tâches de fond que je présente dans Claude Cowork.

Comme le CLI, l'onglet Code demande un abonnement payant : si un clic sur Code vous propose de changer de formule, votre compte est en formule gratuite. L'application n'accepte pas de clé d'API Console ; pour ce cas, passez par le CLI.

Mettre à jour Claude Code

Avec l'installeur natif, rien à faire : Claude Code vérifie les mises à jour au démarrage et pendant l'utilisation, les télécharge en arrière-plan et les applique au lancement suivant. Pour forcer la mise à jour tout de suite :

claude update

Les autres méthodes se mettent à jour à la main :

MéthodeCommande de mise à jour
Homebrewbrew upgrade claude-code (ou claude-code@latest)
WinGetwinget upgrade Anthropic.ClaudeCode
aptsudo apt update && sudo apt upgrade claude-code
dnfsudo dnf upgrade claude-code
npmnpm install -g @anthropic-ai/claude-code@latest

Le canal se règle dans /config, rubrique Auto-update channel : latest, le choix par défaut, reçoit chaque version dès sa sortie ; stable reste environ une semaine en retrait et saute les versions qui ont posé problème. Pour couper les mises à jour automatiques, ajoutez "DISABLE_AUTOUPDATER": "1" dans la section env de votre fichier settings.json.

Désinstaller Claude Code

Supprimez d'abord le programme. Installeur natif, sur Mac, Linux et WSL :

rm -f ~/.local/bin/claude
rm -rf ~/.local/share/claude

Installeur natif sous Windows, dans PowerShell :

Remove-Item -Path "$env:USERPROFILE\.local\bin\claude.exe" -Force
Remove-Item -Path "$env:USERPROFILE\.local\share\claude" -Recurse -Force

Pour les autres méthodes : brew uninstall --cask claude-code, winget uninstall Anthropic.ClaudeCode, sudo apt remove claude-code, sudo dnf remove claude-code ou npm uninstall -g @anthropic-ai/claude-code.

Vos réglages, l'historique des sessions et la configuration des serveurs MCP restent dans ~/.claude et ~/.claude.json. Supprimez-les seulement si vous voulez tout effacer, et désinstallez avant l'extension VS Code, le plugin JetBrains et l'application de bureau, qui recréent ce dossier :

rm -rf ~/.claude
rm ~/.claude.json

Si claude répond encore après tout cela, il reste une seconde installation, souvent une ancienne version npm ou un alias laissé par un ancien installeur.

Ajouter Claude Code au PATH

Sur Mac, avec Zsh, le shell par défaut :

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

Sur Linux et WSL, avec Bash, même ligne en remplaçant ~/.zshrc par ~/.bashrc. Sous Windows, dans PowerShell :

$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

Redémarrez ensuite le terminal et relancez claude --version.

Le terminal fait peur, et c'est le seul vrai obstacle

La difficulté n'est jamais l'agent, qui parle français et explique ce qu'il fait. C'est l'écran noir. Une fois passée la première demi-heure, la question ne se pose plus. Si cet obstacle vous bloque, commencez par l'application de bureau ou l'extension VS Code : le moteur est le même.

Et après l'installation ?

Claude Code s'enrichit ensuite de trois façons :

  • Les skills : des savoir-faire réutilisables (une procédure d'audit, une checklist de publication) que l'agent charge quand il en a besoin. Le mode d'emploi est dans Claude Skills.
  • Les serveurs MCP : la connexion à vos outils (Search Console, crawler, base de données). Voir c'est quoi un serveur MCP.
  • Les plugins : des paquets qui regroupent skills, agents et serveurs MCP, à installer avec /plugin dans une session.

La moitié de ce que je lui confie n'a rien à voir avec du développement : convertir des centaines d'images, croiser deux exports, vérifier un site avant sa mise en ligne. Quand une tâche revient chaque semaine, elle devient un programme qui tourne seul : c'est le type de chantier que je mène en mission d'automatisation IA.

Questions fréquentes

Comment installer Claude Code ?

Ouvrez un terminal et collez la commande de votre système : curl -fsSL https://claude.ai/install.sh | bash sur Mac, Linux et WSL, irm https://claude.ai/install.ps1 | iex dans PowerShell sous Windows. Ouvrez ensuite un nouveau terminal et vérifiez avec claude --version. Lancez enfin claude dans le dossier de votre projet pour vous connecter.

Claude Code est-il gratuit ?

L'installation est gratuite, pas l'usage. Claude Code demande un abonnement Claude Pro, Max, Team ou Enterprise, ou un compte Console facturé au token. La formule gratuite de Claude ne donne pas accès à Claude Code, ni dans le terminal ni dans l'application de bureau.

Faut-il installer Node.js pour utiliser Claude Code ?

Non. L'installeur natif fournit un programme autonome qui n'a pas besoin de Node.js. Node.js, en version 22 ou plus, ne sert que si vous choisissez l'installation par npm, et même dans ce cas le paquet installe le même programme natif.

Où s'installe Claude Code ?

Avec l'installeur natif, la commande claude est placée dans ~/.local/bin sur Mac et Linux, et dans %USERPROFILE%\.local\bin sous Windows. Les versions sont rangées dans ~/.local/share/claude. Vos réglages et votre historique se trouvent dans le dossier ~/.claude et le fichier ~/.claude.json.

Comment avoir Claude Code dans VS Code ?

Ouvrez la vue Extensions de VS Code (Ctrl + Maj + X, ou Cmd + Maj + X sur Mac), cherchez « Claude Code » publié par Anthropic et installez-le. Ouvrez un fichier, cliquez sur l'icône Spark en haut à droite de l'éditeur, puis connectez-vous. Il faut VS Code 1.94 ou plus récent et un compte Claude payant ou Console.

Claude Code fonctionne-t-il sur Windows sans WSL ?

Oui. Avec l'installeur natif, Claude Code tourne directement sous Windows 10 (version 1809 et plus) et Windows 11, depuis PowerShell ou CMD, sans droits administrateur. Git for Windows est recommandé pour que l'agent dispose de Git Bash. WSL 2 reste utile si vos projets demandent des outils Linux ou l'isolation des commandes.

Comment mettre à jour Claude Code ?

Avec l'installeur natif, les mises à jour se font seules en arrière-plan, et la commande claude update force la dernière version. Avec Homebrew, WinGet, apt, dnf ou npm, la mise à jour est manuelle : brew upgrade claude-code, winget upgrade Anthropic.ClaudeCode ou npm install -g @anthropic-ai/claude-code@latest, par exemple.

Comment installer un plugin dans Claude Code ?

Dans une session, tapez /plugin pour parcourir les plugins disponibles, ou /plugin install suivi du nom du plugin et de sa marketplace, par exemple commit-commands@claude-plugins-official. Choisissez ensuite la portée : pour vous dans tous vos projets, pour tous les collaborateurs du dépôt, ou pour vous dans ce dépôt seulement.
